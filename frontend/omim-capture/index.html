請先在分析系統登入，再重新整理這一頁。

1. 安裝擴充功能（Chrome / Edge）

擴充功能原始碼在 repo 的 reference/omim_capture/。

  1. 開啟 chrome://extensions（Edge 為 edge://extensions），打開「開發人員模式」。
  2. 按「載入未封裝項目」，選本機 repo 裡的 reference/omim_capture 資料夾（裡面直接看得到 manifest.json 的那一層）。
  3. 更新：在 repo git pull 後，到擴充功能頁的 NGS OMIM Capture 卡片按「重新載入」。
  4. 沒有本機 repo 時：下載 ngs-omim-capture.zip，解壓縮到固定位置後同樣用「載入未封裝項目」載入。

2. 產生 capture token，貼到擴充功能設定

這個 token 只會顯示一次，請複製後貼到擴充功能的「設定」頁：

名稱建立時間最後使用

3. 在 OMIM 頁面按 Capture

打開 omim.org/entry/{MIM}，右下角會出現「NGS OMIM Capture」面板，顯示平台目前的狀態（缺說明、OMIM 已更新、已是最新）。按「Capture 送到平台」後，擴充功能會自動展開 Clinical Synopsis 並把頁面內容送回平台。平台 OMIM 資料庫啟用後，面板會出現「採用到平台」按鈕，採用後卡片與報告即改用新內容；也可以在下方擷取詳情裡採用。
