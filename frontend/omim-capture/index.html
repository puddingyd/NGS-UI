OMIM 擷取（擴充功能 PoC）

← 回分析系統

請先在分析系統登入，再重新整理這一頁。

1. 安裝擴充功能（Chrome / Edge）

  1. 下載 ngs-omim-capture.zip，解壓縮到固定位置（之後不要刪除這個資料夾）。
  2. 開啟 chrome://extensions（Edge 為 edge://extensions），打開右上角「開發人員模式」。
  3. 按「載入未封裝項目」，選擇解壓縮後的 omim_capture 資料夾。
  4. 更新版本時，重新下載解壓縮覆蓋，再到擴充功能頁按「重新載入」。

2. 產生 capture token，貼到擴充功能設定

這個 token 只會顯示一次，請複製後貼到擴充功能的「設定」頁：

名稱建立時間最後使用

3. 在 OMIM 頁面按 Capture

打開 omim.org/entry/{MIM}，右下角會出現「NGS OMIM Capture」面板，顯示平台目前的狀態（缺說明、OMIM 已更新、已是最新）。按「Capture 送到平台」後，擴充功能會自動展開 Clinical Synopsis 並把頁面內容送回平台。這個階段只保存與比對，還不會改寫 OMIM.xlsx。
