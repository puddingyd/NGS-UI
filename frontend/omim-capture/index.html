安裝擴充功能與 token 設定

1. 安裝擴充功能（Chrome / Edge）

擴充功能原始碼在 repo 的 reference/omim_capture/。

  1. 開啟 chrome://extensions（Edge 為 edge://extensions），打開「開發人員模式」。
  2. 按「載入未封裝項目」，選本機 repo 裡的 reference/omim_capture 資料夾（裡面直接看得到 manifest.json 的那一層）。
  3. 更新：在 repo git pull 後，到擴充功能頁的 NGS OMIM Capture 卡片按「重新載入」。
  4. 沒有本機 repo 時：下載 ngs-omim-capture.zip，解壓縮到固定位置後同樣用「載入未封裝項目」載入。

2. 產生 capture token，貼到擴充功能設定

這個 token 只會顯示一次，請複製後貼到擴充功能的「設定」頁：

名稱建立時間最後使用

3. 在 OMIM 頁面按 Capture

打開 omim.org/entry/{MIM}，右下角會出現「NGS OMIM Capture」面板，顯示平台目前的狀態（缺說明、OMIM 已更新、已是最新）。按「Capture 送到平台」後，擴充功能會自動展開 Clinical Synopsis 並把頁面內容送回平台；接著可在面板按「採用到平台」，或回到這一頁的「待採用」清單逐筆或全部採用。每月一次開 omim.org/statistics/updates（OMIM Update List），在面板按「擷取缺少的月份」，平台就會把 OMIM 之後更新過的頁面列進待補清單。想連續處理時，按面板待補清單的「Capture 並前往」，會擷取目前這一頁後直接前往下一步，最後再回這一頁「全部採用」。

    待補清單

    以基因為單位：先開基因頁同步疾病清單，再補這個基因每個缺說明或超過一年未更新的疾病。順序是「進行中的基因」（基因頁已同步，或因共用疾病已被部分更新）→「OMIM 有更新」（做過的基因或疾病，OMIM 之後又改了，依下方「OMIM 更新清單」判斷）→「疾病相關基因中，基因頁還沒同步的」→ 其他；擴充功能的「前往」會先把同一個基因做完。基因頁和平台對不上的項目列在「待確認」，可直接保留或移除。

    OMIM 更新清單

    開啟 OMIM Update List

    在 OMIM Update List 頁面用擴充功能按「擷取缺少的月份」，平台就知道哪些內容是 OMIM 在我們擷取（或 OMIM.xlsx Done 日期）之後又更新的，並列入待補清單的「OMIM 有更新」。
