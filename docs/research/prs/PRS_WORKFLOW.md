# PRS 全流程、開發驗證與方法限制

更新：2026-11-10｜平台 v10.04｜涵蓋 CHD 與新增五疾病的現行共用流程。

本流程由原始 gVCF 計算固定模型分數，與東亞參考者比較百分位，再結合 INTERVENE 相對風險及台灣人口統計估算絕對風險。目前已完成技術一致性與原論文點估計重現；**尚未完成台灣實際發病追蹤驗證，結果僅供研究**。百分位是排名，不是發病機率。

## 1. 整體架構

```text
一次性準備：PGS 權重＋GRCh38 參考基因型 → 固定位點、補值頻率、各疾病參考分布

三級 postprocessing（不需要年齡或病史）
原始 gVCF → 共用基因型重建與品質檢查 → 六疾病 PRS score → 六疾病 percentile
                                                        ↓ 先發布表格
                          共用祖源分析＋各疾病品質門檻 → 完成三級後處理

個案 PRS 頁面（通過上述門檻後）
評估年齡＋性別＋各疾病病史 → INTERVENE HR＋台灣 GBD2019 → 10年／20年／至80歲風險
                                                         → 六圖比較、保存評估、健檢報告
```

- 六疾病共用一次 gVCF 掃描、一次六欄 PLINK 計分、一次祖源分析；各疾病的權重、分布與風險參數分開。
- **計分完成就可顯示 score／percentile；祖源分析完成且符合要求，才能計算風險。** 重跑時也可能保留上一次已發布的分數，須查看工作狀態。
- 三級勾選 PRS 時，等待其計分與祖源／品質檢查收尾才完成整個工作；未勾選、失敗或需更新者，可在個案 PRS 卡片補跑。臨床風險由使用者另外按「風險計算」。

### 疾病與資料對應

權重使用 PGS Catalog 的 **INTERVENE_MegaPRS** 系列 GRCh38 harmonized 檔，沒有重新訓練 SNP 權重。相對風險採原研究愛沙尼亞生物資料庫（EstBB）；下列分層依原文模型選擇，不是一律套相同 HR。

| 疾病 | PGS 模型 | GBD2019 基準類別 | EstBB HR 分層 |
|---|---|---|---|
| 冠狀動脈心臟病（CHD） | [PGS004879](https://www.pgscatalog.org/score/PGS004879/) | Ischemic heart disease | 男性年齡＋性別；女性性別 |
| 第二型糖尿病（T2D） | [PGS004870](https://www.pgscatalog.org/score/PGS004870/) | Diabetes mellitus type 2 | 年齡＋性別 |
| 全部癌症（All cancers） | [PGS004875](https://www.pgscatalog.org/score/PGS004875/) | Total cancers | 年齡 |
| 乳癌 | [PGS004869](https://www.pgscatalog.org/score/PGS004869/) | Breast cancer | 完整樣本 HR；僅估算女性風險 |
| 心房顫動（AF） | [PGS004878](https://www.pgscatalog.org/score/PGS004878/) | Atrial fibrillation and flutter | 年齡＋性別 |
| 癲癇 | [PGS004881](https://www.pgscatalog.org/score/PGS004881/) | Idiopathic epilepsy | 年齡 |

## 2. 每個階段怎麼做

### ① 一次性建立固定參考模型

1. 下載指定版本官方權重，核對 SHA256、PGS ID、GRCh38 座標及等位基因；以完整 HGDP＋1000 Genomes v1 參考 PGEN 匹配。使用 Python、SQLite、PLINK 2、dbSNP157 及 GRCh38 FASTA；多個可能匹配不任選，反向互補須有 dbSNP 身分證據。
2. 固定使用排除親緣後的 **3,330 名參考者**（原始3,942名，排除612名），計算補值所需頻率；其中固定 **735 名東亞參考者（EAS735）**提供各疾病分數分布。各病共用參考者，但不共用同一個分布。
3. CHD 沿用既有610,305位點及原分布；新增五疾病須各自至少匹配原始權重位點的99.5%。實際固定數量記在 `manifest.json`，不把官方原始列數當成成功匹配數。六模型準備完成，且3,330人CHD分數回歸通過後，才允許啟用。
4. **問題與處理：** 參考者、權重或頻率一改，分數尺度就可能改變；因此模型檔與來源都鎖定checksum，更新須另建版本與驗證，不直接覆寫鎖。模型準備只做一次，不在每次載入個案時重建。

### ② gVCF → 可靠基因型

1. 讀取與三級來源相符的單一樣本GRCh38 gVCF及索引；不能把 variant-only VCF 中「沒出現」的位點當成正常0/0。
2. 六模型位點取聯集，每條常染色體只掃一次。沿用凍結版重建規則，結合明確ALT紀錄與reference blocks：只接受可判讀的二倍體GT、`FILTER=PASS`、DP≥10、GQ≥20；block優先使用 `MIN_DP`，沒有時才用DP。
3. 多等位位點只投影目標allele；GT若含其他ALT、低品質、無覆蓋或與FASTA不符，記為缺失，不強改成0/0。同座標紀錄與重疊indel要逐一判斷，不能取第一筆。
4. 用 bcftools／samtools 讀取與核對資料，匯入PLINK PGEN後再匯出VCF，逐位點核對REF／ALT／dosage，防止格式轉換改變基因型。
5. **問題與處理：** A/T、C/G回文SNP仍有股向歧義；目前採 `assume-direct` 研究假設。準備階段先核對來源股向，個案不因不匹配就任意翻股；可疑或不可靠位點進缺失稽核，這不表示股向問題已完全消除。

### ③ 基因型 → PRS raw score

1. 每個疾病在固定的位點集合上計算：

   ```text
   score = Σ(可靠位點的 beta × effect-allele dosage)
         + Σ(缺失位點的 beta × 2 × p_effect_3330)
   ```

2. dosage為0／1／2；缺失以固定3,330人effect-allele頻率的平均值補入。這是平均補值，**不是**推回個案真實基因型，也不是依單倍型做imputation。
3. 一次PLINK六欄計分，包含REF作effect allele時所需的方向／常數校正；另由Python逐項獨立加總，兩者差異須≤`1e-5`，並保留 observed／imputed contribution、缺失原因與高權重缺失清單。
4. **問題與處理：** UI稱「原始PRS score」的是上述固定模型、含補值的總分；不是舊Nextflow只對交集位點計出的SUM。不同疾病原始分數也不能直接比大小。缺失較多會使分數往參考平均靠近，所以還要檢查可靠位點比例。

### ④ score → percentile，並完成祖源／品質檢查

1. 每病與自己的EAS735分布做經驗累積分布（ECDF）：`percentile = 100 × count(reference score ≤ 個案score) / 735`；不是用常態分布Z值換算。排名最小步距約0.136百分點，顯示小數不表示有同等精密度。
2. 用 `pgscatalog/pgsc_calc v2.3.0`、Nextflow、Apptainer及FRAPOSA OADP，投影至HGDP＋1kGP的 `SuperPop`。六疾病共用固定CHD位點政策，避免新增疾病改變祖源標記集合。
3. 計算風險須有明確EAS、非低信心祖源、有效PCA標記，且該病可靠位點比例≥99.5%。這個**個案品質門檻**與①的**模型準備匹配率**是兩件事，均不是經臨床驗證的cutoff。距20／40／60／80／90／95邊界≤2百分點或有高權重缺失時需審查。
4. **問題與處理：** 735人不是台灣常模，且祖源目前用CHD位點子集，並非獨立全基因組祖源panel。非EAS或不確定者可以查看條件式排名，但不放行風險；不把「來自台灣」直接當成已通過祖源檢查。

### ⑤ percentile → absolute risk

1. 使用未四捨五入的百分位分七組：`<20、20–40、40–60、60–80、80–90、90–95、≥95`；邊界歸右組，40–60為HR=1的參考組。不是把percentile直接乘台灣發生率。
2. 從作者固定版本原檔讀取EstBB七組HR／SE；有年齡分層時，對log(HR)與組內年齡中位數做 `1/SE²` 加權線性回歸，超出觀察年齡時固定在端點；再取各五歲區間的HR。其他模型採該性別或全樣本HR。不是用發表的風險結果反推係數。
3. 基準採作者公開GBD2019中的台灣、2019、年齡別及性別別資料：**發生率、盛行率、疾病死亡率、全死因死亡率**；乳癌另用作者整理的乳癌基準檔。原Rate除以100,000，盛行率轉比例；不用年齡標準化率，也不能把盛行率當年度發生率。
4. 先按各組比例 `q=(.2,.2,.2,.2,.1,.05,.05)` 校準人口發生率，再計算：

   ```text
   λ_g = I_population × HR_g / Σ(q × HR) / (1 − prevalence)
   μ   = 全死因死亡率 − 該疾病死亡率
   ΔF  = S × λ_g/(λ_g+μ) × [1 − exp(−(λ_g+μ) × Δt)]
   S   ← S × exp(−(λ_g+μ) × Δt)
   ```

   λ是發病hazard，μ是先因其他原因死亡的hazard；S從評估時的1開始，代表仍存活且未發病的機率。跨五歲區間逐段累加ΔF，區間內假設速率固定，零總hazard時增量為零。
5. **適用條件：** 評估時20至未滿80歲、仍存活且尚未罹患該病；女性才提供乳癌風險。≤60歲提供完整20年，≤70歲提供完整10年，均可算目前至80歲；超出80歲的完整期間回不適用，不截短冒稱10／20年，也不估復發或出生至80歲風險。
6. **問題與處理：** 目前是歐洲HR＋東亞排名＋台灣人口率的外推。假設每組的盛行率與其他死因死亡率相同，且分位組比例可沿用；2019年率不隨未來世代改變。這些假設尚未由台灣追蹤資料驗證，同組同年齡同性別會得到相同風險。

### ⑥ 保存、UI與健檢報告

1. 填寫必要的年齡、模型使用的性別及各疾病病史，再按「風險計算」。新病史表單預設「否」只是輸入預設值，使用者仍須核對；已有疾病或未知病史的列不估風險，乳癌已有病史與全部癌症填否會拒絕。
2. 保存獨立評估快照，綁定個案來源、score、模型／參數hash及臨床輸入；資料變動要重算。UI呈現六疾病表格與個案對40–60組的六張曲線，不同圖的縱軸刻度可能不同。
3. 報告匯出前後再驗證資料與結果；至少一疾病有有效風險評估才可勾選PRS。已患病／不適用疾病仍列已分析的百分位與原因。頁面分數較多位數，報告一位小數採四捨五入，不能拿顯示值反推重新計算。

## 3. 開發時比較了什麼，為什麼選目前的方法

### Method 1／2與Model A／B：指計分校準，不是風險HR模型

以下結果取自歷史SOP與2026-11-02交付的驗證紀錄；這次整理沒有重跑這些WGS。

| 開發方法 | 作法與已有結果 | 決策／限制 |
|---|---|---|
| 舊pgsc_calc個案交集 | 不同個案的可用位點不同，連reference SUM也跟著變；兩案reference差異曾由1,861個SNP解釋 | 工具不一定算錯，但個案間尺度不固定；其輔助SUM／percentile不作平台正式值 |
| Method 1：common3 | 三個開發樣本與reference固定共同607,445位點後，reference SUM一致 | 支持「固定集合可消除這項差異」，但集合由這三案決定；新增大量個案會受其缺失影響，不作可擴充的正式模型 |
| Method 2：事先固定集合 | 先以官方CHD與reference相容性固定610,305位點，缺失補2p，再對固定EAS735分布排名 | 採用；新個案不重新決定reference集合，擴充疾病也沿用此原則 |
| Model A | 610,305位點；原官方610,677中排除372個不相容位點 | 主分析，保留較完整資訊並維持已鎖定校準；不是宣稱臨床效能優於B |
| Model B | 在A中再要求EAS與全體reference缺失率均≤1%，保留603,438位點 | CHD敏感度比較，觀察reference缺失影響；不依個案挑較好看的結果，也不與A平均 |

### 原論文重現與現行風險積分的差別

- 原研究五年離散近似：每區間增加 `S × [1−exp(−5λ)]`，再以疾病與其他死因hazard更新S。用於重現Supplementary Data 4的Estonia點估計。
- UI使用區間內連續競爭風險積分（`competing_exact_v1`），以便從任意評估年齡起算。它與原近似不是同一算法；既有CHD台灣比較網格（20–75歲、每5歲起點的10年／至80歲）最大差約1.443612百分點，不能宣稱逐值相同。

| T2D | 224 | 0.0049983042 |

## 4. 方法風險與曾遇到的問題

| 問題 | 目前處理／仍有的限制 |
|---|---|
| CHD與GBD IHD範圍不同 | CHD診斷碼含不穩定心絞痛、心肌梗塞、其他急／慢性缺血性心臟病與心跳停止；GBD IHD依急性心肌梗塞、慢性IHD等估計。不是單一心肌梗塞或心血管死亡風險 |
| 全部癌症名稱與來源不完全等同 | 原研究碼未涵蓋所有血液惡性腫瘤；也不是各癌症風險相加。它與乳癌事件重疊，兩個風險不能相加 |
| 癲癇、AF與GBD定義差異 | 原研究G40癲癇搭配GBD特發性癲癇；AF基準含心房撲動。不能直接解讀為所有原因癲癇或中風風險；T2D不含第一型／妊娠糖尿病 |
| 全部癌症HR分組標籤方向相反 | 反向對應原CSV標籤後重現224筆，不倒數HR；這是驗算支持的來源對應推論，仍待作者確認，不是作者明文轉換 |
| AF 20–29歲資料為零／缺列 | 原始發生與盛行明列零，四格疾病死亡由作者補零；只允許這個已稽核例外。模型零值不表示不會發病，不把其他缺列一律補零 |
| Log分數與表格不同 | 舊raw SUM、祖源交集SUM、固定模型含補值SUM不是同一量。正式表格只讀已核對的固定模型summary；摘要Log避免把輔助SUM呈現為正式分數，完整Log供追查 |
| 祖源格式錯誤後久等 | 曾缺PGS表頭 `trait_reported`；現在於個案目錄補完整metadata，變異列不變，先以pgscatalog-format容器預檢；終止型Nextflow錯誤會停止相關程序並顯示原因 |
| 容器暫存占滿系統磁碟／繼承已刪除的三級tmp | 個案 `.runtime/tmp` 明確掛載至容器TMPDIR、`/tmp`、`/var/tmp`；清除父job一次性bind，執行前測試實際讀寫，不能只設定host TMPDIR |
| 缺件、版本不同或併發更新 | 樣本鎖、工作lease、固定輸入與輸出checksum、分階段原子發布；失敗保留已完成計分，來源改變拒用舊結果。不為了跑通而降低門檻或修改model lock |

此外，尚未納入血壓、血脂、血糖、BMI、吸菸、家族史、罕見致病變異或治療效果，未提供個人不確定性區間。固定子集、平均補值與小型東亞參考分布對HR外推的影響，均需額外研究。

## 5. 程式、資料位置與後續方向

- 現行程式：`research/prs/multidisease/{prepare,reconstruction,run,ancestry_input}.py`；風險為 `absolute_risk/{build_multi,multi,engine}.py`。`scoring_v211/`保留CHD凍結核心與歷史證據，`docs/research/prs/PGS004879_integrated_v2/`是較早交付快照，舊路徑／狀態不能直接當現行設定。
- 套件：Python、SQLite；資料準備另用openpyxl／zstd，運算用bcftools／samtools、PLINK 2容器（鎖定2.00a5.10映像）、pgsc_calc v2.3.0、FRAPOSA、Nextflow與Apptainer。實際工具／容器及輸入版本應連同job紀錄保存，不以更新到最新版取代版本核對。
- 共用模型放 `NGS_UI_HOME/biotools/prs/multi_v1/`；個案大型重建、audit及Nextflow放既有 `nf_work/prs/{個案ID}/`，可由work root設定覆寫，沿既有SSD bind mount。正式結果、QC及風險快照發布至個案 `08_postprocessing/`；不把個案產物寫回原PRS開發專案。
- **優先補驗：** 六疾病真實WGS端對端、各病缺失與高權重位點、Nextflow中途task恢復、批次負載與資源峰值；再增加獨立全基因組祖源檢查與更多技術驗證樣本。
- **台灣percentile：** 以合適的台灣參考資料（如獲准的TWB或具代表性的院內資料）建立同一計分流程的分布，處理親緣、批次與抽樣偏差；先比較EAS735與台灣排名／分組差異，再另行升版，不能只換分母或沿用舊hash。台灣分布本身仍不等於風險已驗證。
- **台灣risk驗證：** 連結各病診斷日期、追蹤期間及死亡，核對endpoint與失訪，評估預測人數對實際發病、校準曲線、區辨力及分層表現；必要時重估HR／基準hazard。更新GBD年度、加入臨床因素與不確定性傳播也須另版驗證。TWB／BBJ目前未納入；病例對照OR不能直接當追蹤HR。
